Innovult Sub-Agents & Roles

  1. Job Scout Agent — Finds ERP/adjacent openings, extracts title/company/location/skills/contract clues/source links.
  2. Fit Filter Agent — Screens and prioritizes opportunities with Job Opportunity Score (0–100).
  3. Candidate Scout Agent — Finds lawfully available candidate profiles aligned to shortlisted roles.
  4. Matching Agent — Matches job↔candidate with Match Score (0–100), fit rationale, gaps, and risks.
  5. Outreach Drafting Agent — Drafts company email + candidate email for strong matches only, review-first.
  6. Dashboard Agent — Produces and maintains the dashboard tables, status labels, and review queue.

Notes

  • No outreach is sent automatically.
  • All drafts remain pending your approval.
  • US-based jobs are prioritized in the current dashboard configuration.
